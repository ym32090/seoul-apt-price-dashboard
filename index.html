공식 데이터 확인

각 기관의 자료를 내려받은 다음 위 버튼으로 가져올 수 있습니다.

한국부동산원 · 아파트 평균매매가격 ↗한국부동산원 · 통계조회(중위가격 검색) ↗KB부동산 데이터허브 ↗국토부 · 아파트 매매 실거래 API ↗네이버부동산 ↗

출처별 지원

  • KB: 기본 5개월 + 검증된 공식 월별 자료를 JSON 또는 수동 파일로 확장
  • 한국부동산원: 공식 CSV/XLSX 또는 인증키를 이용한 사전 갱신 결과(JSON)
  • 국토부: 실거래 원자료와 월별 집계 파일은 구분(월별 집계 업로드 지원)
  • 네이버: 공식 공개 통계 API 확인 안 됨, 적법하게 확보한 파일만 가져오기

데이터 연결 구조

정적 JSON은 모든 방문자에게 표시되고, CSV/XLSX 직접 가져오기는 현재 브라우저에만 저장됩니다.

  • GitHub Pages는 서버가 없어 R-ONE API를 직접 호출하지 않습니다.
  • 공식 API 키는 HTML에 넣지 않습니다.
  • 공개 데이터 갱신은 GitHub Actions 수동 실행 또는 별도 PC 갱신 후 JSON 업로드 방식입니다.
  • KB/한국부동산원 수치는 서로 다른 표본 및 산정 방법입니다.

통계 해석 유의

평균·중위가격의 단순 증감률은 통계표의 두 월 가격 차이이며, 동일 아파트의 순수 가격 상승률이 아닙니다.

  • KB 시세·부동산원 표본가격·국토부 실거래가격은 산출방식이 다릅니다.
  • 한국부동산원은 표본 변화로 인한 시계열 불연속에 주의를 당부합니다.
  • 시장 상승률 판단에는 별도 매매가격지수를 함께 확인하세요.
  • 국토부 실거래는 신고 지연·거래 구성 변화가 영향을 줍니다.
